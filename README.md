# Marcus Command Center

A production-ready Next.js application shell for the Marcus Command Center — a dark luxury AI creative command center.

## Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Language**: TypeScript
- **Deployment**: Vercel

## Design System

| Token | Value |
|---|---|
| Background | `#0A0B10` |
| Card Background | `rgba(255,255,255,0.08)` |
| Accent Violet | `#7C3AED` |
| Accent Cyan | `#06B6D4` |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.

## Deployment

This project is optimized for deployment on [Vercel](https://vercel.com). Push to `main` to trigger an automatic deployment.
